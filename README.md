# גול360

אפליקציית ספורט בעברית (PWA) — תוצאות חיות, חדשות, טבלה ופרופילי שחקנים.

ניתן להוסיף לדף הבית בטלפון (Add to Home Screen).

## הרצה מקומית

```bash
npm install
npm run dev
```

האתר נפתח ב־`http://localhost:5173`.

## בנייה

```bash
npm run build
npm run preview
```

## הוספה לדף הבית

- **Android / Chrome:** בתפריט הדפדפן בחרו ״התקן אפליקציה״ / ״הוסף למסך הבית״, או לחצו על הבאנר באפליקציה.
- **iPhone / Safari:** שיתוף → ״הוסף למסך הבית״.

## תוכן

הנתונים לדוגמה (משחקים, חדשות, טבלה) נמצאים ב־`src/data/sports.js`.
